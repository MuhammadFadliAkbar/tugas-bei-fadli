WEBSITE KUNJUNGAN INDUSTRI - BURSA EFEK INDONESIA

CARA MEMBUKA
1. Ekstrak folder website-bei-teman.zip.
2. Buka folder website-bei-teman.
3. Klik dua kali index.html atau klik kanan > Open with > browser.

CARA MENGGANTI FOTO
1. Siapkan minimal 10 foto dokumentasi kunjungan.
2. Buka folder assets/img.
3. Ganti file foto1.svg sampai foto10.svg dengan foto milik sendiri.
4. Jika menggunakan JPG/PNG, ubah juga nama file pada bagian src dan data-image di index.html agar sesuai.
   Cara termudah: ubah foto menjadi JPG/PNG tetapi beri nama foto1.jpg, foto2.jpg, dst,
   lalu ganti ekstensi .svg menjadi .jpg di index.html.

CARA MENAMBAHKAN VIDEO
1. Masukkan video vlog berdurasi 90 detik ke assets/video/.
2. Beri nama vlog-bei.mp4.
3. Buka index.html di browser dan tekan tombol play.

YANG PERLU DISESUAIKAN
- Sesuaikan tanggal, urutan kegiatan, dan isi refleksi dengan kunjungan sebenarnya.
- Isi identitas/nama dan kelas jika diperlukan oleh guru.
- Gunakan foto dan video dokumentasi sendiri.

CATATAN
Website menggunakan HTML, CSS, dan JavaScript murni. Google Fonts membutuhkan koneksi internet.
